# Бухгалтерия
Проект "Бухгалтерия" — учебная программа для знакомства с организацией структуры Python-проекта, импортами, пакетами и модулями.
**Автор:** *Корецкий Владимир*  
  
## Описание
Программа представляет собой простую структуру для ведения бухгалтерского учета. Реализованы базовые модули для расчета зарплаты и работы с сотрудниками.  
  
## Структура проекта  

```
accountancy/
├── application/
│   ├── __init__.py
│   ├── salary.py          # Модуль для расчета зарплаты
│   └── db/
│       ├── __init__.py
│       └── people.py      # Модуль для работы с сотрудниками
├── main.py                # Главный модуль приложения
├── dirty_main.py          # Альтернативный импорт (доп. задание)
├── requirements.txt       # Зависимости проекта
└── README.md             # Этот файл
```

## Запуск
Для запуска программы выполните:

```
python main.py
```

Или для альтернативного варианта:

```
python dirty_main.py
```

## Модули
application/salary.py
Содержит функцию calculate_salary(), которая выводит информацию о расчете зарплаты с текущей датой.

application/db/people.py
Содержит функцию get_employees(), которая выводит список сотрудников с текущей датой.

main.py
Главный модуль, который импортирует и вызывает функции из пакета application.

### Используемые импорты:

```
from application.salary import calculate_salary
from application.db.people import get_employees
dirty_main.py (дополнительное задание)
```

Альтернативный модуль, использующий импорт всех функций через *:

```
from application.salary import *
from application.db.people import *
```

Дата и время
При каждом вызове функций выводится текущая дата и время с использованием модуля datetime.
